## Повторение проверки

После сборки и загрузки:

```bash
node scripts/verify-archive.mjs 19cgyN2Z6fCJAtDP 20 3
```

Скрипт проверяет локальный архив и записывает verification.json рядом с manifest. Не читает credentials и не обращается к сети. На больших архивах проверка использует память для точной сверки кратности событий.

Архив исключён из Git: data/19cgyN2Z6fCJAtDP/20/. Подробные результаты — verification.json и mcp-verification.json. Для исходных страниц учитываются последовательные page-Friendlies-N.json/page-Enemies-N.json до первого nextPageTimestamp=null, а не произвольный glob: после прерванных попыток могут оставаться более поздние файлы предыдущего запуска.

Это проверка загрузки, хранения и инструментов исследования, а не сравнительный разбор ротации. Референсный бой пока не предоставлен. Наличие полного API-архива не гарантирует, что сам combat log содержит все возможные данные; uptime остаётся наблюдаемой оценкой.
